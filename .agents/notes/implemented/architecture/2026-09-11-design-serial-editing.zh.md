# 同一作品的人工与 Agent 串行编辑

Status: implemented
Translation: current

[English](2026-09-11-design-serial-editing.md)

## 摘要

此前方案允许 Agent 创作期间继续手工编辑同一画布，需要把人机冲突作为常规用户流程。现按已确认方向改为串行编辑：派发前保存手工修改，所属画布只读至 Agent 执行和产物处理结束，再恢复编辑。应用复用 Lody 的执行状态并控制通用画布只读能力，Bento 不接入 Agent 生命周期；反向同步与版本保护保留，文件冲突由 Agent 处理。代价是用户不能在同一作品生成期间手工改稿；其他作品仍可编辑。已有冲突另存暂留为非正常并发的保稿手段。（事实更正：串行编辑边界随后由 T02 实现，见文末 Outcome；原文“运行时尚未实现”为方案阶段状态。）

## 取代的约定

本决定取代[主计划](2026-09-09-graphic-design-platform.zh.md)、[读取同步](../../rejected/architecture/2026-09-10-design-sync-hooks.zh.md)及[实时预览](2026-09-11-pptd-live-preview.zh.md)中允许人机同时修改同一稿的目标。产品合同更新到 [Spec](../../../../specs/graphic-design-platform.zh.md)，P1/P2 历史实施记录保留。它补充[范围复核](../../proposed/simplification/2026-09-11-design-result-feedback.zh.md)，不恢复结果卡或专用缩略图。

## 最小执行边界

| 时段 | 应用行为 |
| --- | --- |
| 空闲 | 正常手工编辑、保存和导出 |
| 准备派发 | 暂停所属作品的新人工变更，flush 并确认待完成保存；成功后冻结版本、选区和输入，再启动 Agent |
| 保存/启动失败 | 保留输入及编辑内容；确认没有运行任务后恢复编辑，不静默丢稿 |
| Agent 执行 | 所属作品所有画布实例只读；允许观看、缩放、切换视图和取消；提交后引用当前稿，其他作品仍可编辑 |
| 工具/权限等待或取消处理中 | 保持只读；发出取消请求不等于任务已结束 |
| Agent 结束后的采集/提交 | 保持只读，复用正式校验、提交或文件冲突诊断；不在最后一条文本输出后解锁 |
| 结果处理结束 | 刷新已提交当前稿，或保留原稿并提供草稿位置和普通错误反馈，然后恢复编辑；失败/取消不自动提交预览 |
| 断连、关闭与重开 | 不因视图消失解锁；恢复先核对真实执行与结果处理状态，未知时暂只读并给出状态。确认无任务和在途提交后恢复 |

此规则按作品/实际关联 workspace 应用，覆盖该作品的讨论回合，不依据提示词猜测是否会改图。未开始的排队回合在实际派发前重新保存并固定基线；同一作品重叠执行使用既有排队/拒绝机制。旧回合迟到的结束消息不得解锁新回合；不为本功能增加独立任务调度或持久锁平台。

只读覆盖文字输入、属性、拖动、粘贴、图片替换、删除、尺寸变更和撤销/重做等文档修改。人工保存、导入等服务入口执行同一检查，不能仅依赖当前窗口按钮。进入只读前的待完成保存必须先排空或明确拒绝，再固定 Agent 基线；进行中的组合输入也不能丢失。Agent 对草稿的写入及本回合的正式提交仍允许，不能被人工写入限制误拦。

应用通过通用只读参数、快照与保存接口接入，Bento 不读取 Agent 状态。只读身份和生命周期复用现有作品关联、运行与结果处理事实；不在模型执行的整个期间持有磁盘提交锁，原子锁只保护实际保存/提交。

## 保留与删减

| 能力 | 新方案 |
| --- | --- |
| 反向同步 | 保留。手工编辑发生在回合之前，Agent 读取时仍须获得最新 PPTD；只读本身不会更新文件 |
| 投影/草稿分离及读取基线 | 保留。同一回合的重读不能覆盖 Agent 草稿或隐式更改基线 |
| 最终版本检查 | 保留。外部程序、旧请求或未覆盖窗口仍可能改变状态，UI 只读不是文件系统沙箱 |
| 人机常规冲突协调 | 删除这一正常产品场景；验证改为运行期间人工修改被拒绝 |
| 已实现的手工冲突另存 | 不再扩展为日常协同功能，暂留异常保稿。仅凭禁止 Agent 期间修改，无法证明空闲时多窗口/外部修改不再发生；彻底删除须先明确保稿出口 |
| 候选工作流 | 已确认删除。修改与重新生成统一提交；冲突由 Agent 重读文件处理，外部文件直接显式导入；已有内容保持可达 |
| 旧 PPTD 自动候选 | 已确认按 P3.0d 删除；串行编辑不意味着旧文件来自本轮。保留已有文件/候选与真正新产物保护 |
| 当前稿与创作预览 | 保留两个来源。运行期间两者都只读，前者已保存、后者未提交；可切换查看 |
| Agent 渲染预览和读图 | 保留，不依赖用户画布是否可编辑 |

2026-09-11 后续[整体收敛](../../proposed/simplification/2026-09-11-design-workflow-convergence.zh.md)进一步删除候选流程和临时预览元素引用需求；这不改变只读生命周期，手工保存异常另存也不在本轮删除。

## 实施与验收

P3.0e 承接串行边界；P3.1 仍实施反向转换与 hooks，P3.7 实施实时预览，P4 接入只读提示和入口状态，P6 验证完整链路。转换与监听可独立开发，但用户路径集成验收必须按新串行边界进行。

验收使用现有确定性设施，覆盖：派发前保存失败/在途保存/组合输入；文字、属性、拖拽、撤销等入口；多实例和另一作品不受影响；权限等待、取消、失败、提交失败；断连重开、迟到结束、后续回合；导入不能绕过只读；旧候选内容保持可读；异常外部修改仍被版本检查拒绝，且未保存内容保留。运行中可看预览并让 Agent 读图，结果处理后恢复编辑。若发现异常脏状态，保留内容并报错，不通过重载清空。

本次不运行产品测试或模型调用，不宣称已解决现有运行时竞态。仅进行文档一致性、链接、大小和公开边界检查；Spec 保持 draft，阶段和本决定保持 proposed。
