# 实时画布的原生视图交接

Status: implemented
Translation: pending

## 摘要

统一画布的实时更新会销毁旧 WebContentsView，但新文档完成加载与布局并不表示其像素已准备好，用户报告了可见闪烁。本次沿用双视图，让新视图在旧画面下面完成资源解码、视口恢复与合成器截图，再置顶并销毁旧视图。回合结束同样保留最后预览到当前稿编辑器准备完成，关闭面板仍立即取消显示。代价是一次临时像素读回以及短暂双视图开销；这提供可验证的像素准备边界，不等于所有操作系统上已经实现肉眼无感，2026-09-19 用户人工验收确认未见闪烁，结论限于本次验收环境。

## 决定与边界

本次是[统一画布](../../proposed/architecture/2026-09-18-unified-live-canvas.zh.md)的显示交接修复，不改变 BentoDoc 权威、草稿因果身份、保存、版本或 Agent 生命周期。用户已授权实施第一步；没有实施常驻渲染器的文档替换，也没有增加截图持久缓存。

- 冻结预览仍串行创建隔离原生视图；字体准备、图片 `decode()`、相同视口恢复及两个 animation-frame 回调之后请求 `capturePage`。得到非空像素再把新视图置顶，同一主进程任务内移除旧视图。
- 首次预览从可见编辑器读取相机；React 不再预先隐藏编辑器。后续帧沿用可见预览相机。
- React 回合阶段 cleanup 仅取消自己的异步结果；阶段切换不立即销毁可见预览。主进程在当前稿 attach 成功且没有活动回合时关闭预览和观察器；实际卸载或面板关闭仍立即释放。
- 隐藏/最小化窗口没有可用的首次显示表面，不强求截图；仍完成资源准备，且不调用窗口 show。首轮隐藏窗口探针据此暴露并修复了空截图导致 attach 失败的问题。可见窗口的交接才执行帧回调和像素读取。
- 解码、像素准备失败保留上一帧；重新检查来源/请求与显示意图，取消后不得重新显示。等待使用主进程期限，不使用固定延迟猜测绘制完成。

Electron 的 [`capturePage`](https://www.electronjs.org/docs/latest/api/web-contents#contentscapturepagerect-opts) 提供渲染像素读取；`stayHidden` 避免截图改变隐藏窗口的可见性。已有子视图通过 [`addChildView`](https://www.electronjs.org/docs/latest/api/view#viewaddchildviewview-index) 调整到顶层。截图返回不能作为物理屏幕呈现完成的证明。

继续只做 debounce 会降低构建过程可见性，不能消除旧画面先销毁的空档。常驻 Bento 增量替换文档可能进一步减少开销，但需要独立验证素材、撤销及状态边界，本步不引入该改动。

## 验证

- `pnpm --dir apps/electron build:app` 通过主进程、前端类型检查及 OSS 构建。
- Electron Node 测试 147/147 通过；画布相关前端测试 20/20 通过，新增“编辑器 attach 未完成时保留最终预览”的回归场景。
- 隔离原生探针 `e2e/artifacts/acceptance/live-canvas-handoff-20260919-02/` 的 `result.json`、`source-preview-result.json`、`version-result.json` 均 passed，进程退出 0、测试端口已释放。该目录保留构建哈希；仅包含合成作品，无真实对话。
- 探针使用真实 worker/Bento/原生视图，记录 12 次非空像素读取，检查旧视图在读取期间仍可见、置顶前已准备像素，以及回到编辑器前保留最后预览。部分读取发生在显式隐藏/重开测试中，不代表每次都存在可见旧视图。连续替换前后相机均为 `{scale: 4, x: 160, y: 100}`；奇数高度长画布缩放保持 1.5。非法草稿、迟到结果、关闭加载中视图、只读、无预览保存入口及原稿/撤销保持均通过。
- `pnpm check` 停在未修改的 `packages/design-authoring/tests/live-fingerprints.test.ts:121`：最近 30 条提交标题没有 `PPTD|Folio`。其他检查不能替代该失败，未修改该断言。

以上是原生交接时序及像素可读性的证据，没有录制操作系统合成画面的连续视频，不能据此宣称全平台“零闪烁”。未启动付费 Agent；历史“复刻这个设计”用例的通过记录不自动转移到本次构建。2026-09-19 用户完成实际窗口人工验收，确认未见闪烁；本次显示交接修复验收通过，不据此扩大为其他平台或完整设计复刻质量的验收。
