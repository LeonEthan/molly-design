# 当前画稿的图片与选区动作

Status: implemented
Translation: pending

## 摘要

T13 为现有画布工具栏接入图片生成、图片编辑、选区风格调整和重新生成。动作复用 T12 的保存后元素引用及普通会话输入，只插入可编辑提示，不自行调用图像服务或提交画稿。图片动作在保存后的当前稿中校验所有选中元素确为图片；作品、基线和稳定 ID 在发送时继续接受原有校验。Bento 手工图片操作与图像连接无关，素材产出和最终文档提交仍由既有 Agent 与设计服务各自负责。真实付费服务未配置，验证必须区分合成服务协议与实际视觉质量。

## 决定与职责

落实 [Issue #15](https://github.com/LeonEthan/Folio/issues/15)，承接
[范围收敛](../../proposed/simplification/2026-09-11-design-result-feedback.zh.md)与
[图像生成/编辑](2026-09-11-image-generation-editing.zh.md)。不新增命令系统、图像作业、候选工作流或素材库。

- `DesignCanvas` 继续使用现有工具栏和 `design.selection`。选择 ID 在 flush 前取得，图像类型在 flush 后的保存文档中验证；混合选区拒绝图片动作，不猜测图片目标。
- 图片生成/编辑提示明确每张选中图片各为目标，风格调整/重新生成明确保留其他内容。普通输入框接收目标 mention 与其范围外的文本后恢复焦点；人可以改写要求、添加参考图并使用已有发送/快捷键。
- 动作不替换输入草稿，不更改已有引用，不隐式更新基线，不直接发送。再次点击动作属于新的输入手势，可以插入相同目标和另一段要求；普通“引用选区”仍去重。
- 选区只来自当前可编辑画稿，来源预览禁用这些入口。运行/权限等待/结束处理中的拒绝复用应用的串行只读检查；动作没有人工写入旁路。
- `folio_generate_image` / `folio_edit_image` 仍先返回 `media/` 下可读取素材。Agent 决定是否使用、如何修改 PPTD，正常完成后由既有采集和版本校验保存。错误不直接替换当前图，不触发自动付费重试。
- 手工插入/裁切/替换继续使用 Bento 已有命令。当前稿保存内嵌实际引用素材；作者文件的 media 和历史内容的内嵌素材保持原有持久化。没有新增清理行为或跨作品图片汇总。

相比另建动作调度器，普通 mention 后附文本复用草稿持久化、编辑、发送和历史呈现。提示词表达用户意图，结构校验不执行创作步骤；图像服务不可用时也不屏蔽手工编辑。

## 验证与限制

- 原生手工探针复用 `ElectronHarness`、已有 Pi ACP 初始会话和实际 Bento DOM：在没有图像连接时使用文件选择器插入 PNG、裁切、替换并读取已保存的素材；四个动作把要求追加到普通输入，保留先前文字；非图片目标明确拒绝，来源预览禁用动作。该手工探针完成全部断言后，Electron 关闭超过 20 秒并以非零状态退出；不能把断言通过表述为该进程完整成功。后续完整图像探针正常退出。
- 原生 Claude 图像探针使用已验证的 Claude Code 2.1.258 / SDK 0.3.258 / ACP 0.70.0 和实际桌面/MCP/HTTP/读取/写入路径。仅模型响应和本地图像 endpoint 为合成固定响应；既有 Image Connection UI 显式填写合成 URL、key 和 model。实际 multipart 上传选中源图片，工具返回素材后由 native Read 产生图片内容，再由普通 Write 修改 PPTD，自然结束后的版本提交保存；其他 shape 不变，关闭画布并重新加载后仍读取新图。
- 请求挂起期间检查画布只读，图片动作报执行中错误，当前保存基线不变。后续图像 endpoint 返回 503，正常结束仍保留完全相同的当前稿；服务记录仅有成功与显式失败的两次图片请求，没有自动图片重试。手工编辑发生在引用建立后时，发送得到陈旧引用错误。
- 使用隔离的 CLI data root、Electron userData 和 daemon endpoint。探针最初假定错误的原生 view URL/元素 DOM 数量及 asset 引用拼写，均更正为实际协议。Claude Auto 权限分类器是另一个模型消费者，固定响应探针不模拟它；最终使用既有 Manual 权限和合成工具的 Allow Once 卡片，不声称验证 Auto 分类器。探针及合成对话/截图/日志留在仓库外，没有捕获或提交真实用户对话。
- 目标 mention 测试覆盖范围外可编辑提示、既有草稿文字、持久化恢复和真实身份展开；既有 T12 作品/版本/删除元素校验继续生效。全量 `corepack pnpm@10.20.0 check` 在原基线和继承 T06/T17 后均通过，包含类型、lint、测试、i18n 和 public/platform 边界；继承冲突另验证 92 项 collector/roundtrip、61 项 baseline/service/outcome/input/digest 和 8 项 Claude hooks/launch。`format`、`docs check` 与 `git diff --check` 通过，docs 无 errors，无 SHA topic，保留既有体积 warnings。

未提供用户图像服务 URL、凭据和模型，没有发起真实付费调用。合成 endpoint 证明本地协议与执行/提交衔接，不能证明真实服务模型兼容性、权限、生成质量或视觉效果。原生探针是手工接受验证，未新增依赖网络/真实时钟的 CI 回归测试；跨平台打包和其他 Agent 的图像 MCP 能力不属于本票实证。
