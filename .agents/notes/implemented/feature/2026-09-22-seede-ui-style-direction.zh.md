# Seede 参考界面与细线图标更新方向

Status: implemented
Date: 2026-09-22
Translation: pending

## 摘要

Molly 原有单色界面在控件几何、图标、对话排版、设置和原生画布之间仍有视觉差异。本轮按用户逐批授权统一了柔和表面、圆角与细线图标，并完成全套 SVG 操作图标、选区边框与实时尺寸、Auto size 选择和 Provider／模型入口调整。用户于 2026-09-23 确认本次 UI/UX 优化结束并要求提交、尝试合并，已实施部分转为 implemented；下文保留各批次当时的范围和证据。后续明确授权的 Role 退役由独立记录承接，历史数据及主要编辑、会话执行能力保持。截图与自动检查分别支持视觉判断和行为回归，不将模拟模型请求称为真实外部服务验收。

## 依据与既有决定

- 视觉依据限于本次提供的 Seede 编辑器截图，不将其视为该产品所有页面、暗色模式、响应式布局或交互行为的证据。截图中的作品配色不属于应用界面配色；原始截图和其中的真实对话不加入仓库。
- [产品 Spec](../../../../specs/graphic-design-platform.zh.md)保留现有侧栏、标签、对话输入和唯一画布；[范围复核](../../proposed/simplification/2026-09-11-design-result-feedback.zh.md)约束功能迁移与结果反馈。
- [黑白视觉刷新记录](../../proposed/feature/2026-09-16-monochrome-chrome-visual-refresh.zh.md)已采用单色、Inter、紧凑控件及小圆角，且后续已将侧栏选中态改为浅 tint。本轮沿用单色方向，局部替代该记录的圆角阶梯、输入和工具坞密度、用户消息反转配色；旧冻结规格不属于实现缺陷。
- [画布 UI 收敛](2026-09-15-canvas-lovart-ui.zh.md)及[原生选区工具栏](../../proposed/architecture/2026-09-17-free-canvas-multi-artboard-research.zh.md)已有独立依据。工具栏视觉更新继续复用当前能力与归属，不恢复已退役的顶部选区带。

## 参考图的设计语言

| 观察                                         | 形成的观感                         | 可迁移的原则                                         |
| -------------------------------------------- | ---------------------------------- | ---------------------------------------------------- |
| 左侧画布工作区约占截图七成，右侧对话约三成   | 作品主导，助手处于辅助位置         | 给画布足够面积；比例只是截图观察，不直接固定所有窗口 |
| 大面积近中性的浅灰，面板及浮动输入框接近白色 | 安静、低装饰，作品容易成为视觉焦点 | 用少数灰阶组织表面，颜色留给内容与真实状态           |
| 很少使用强边框，区域主要靠底色和留白区分     | 减少分割和表格感                   | 削弱重复分隔线，保留必要的可编辑与聚焦信号           |
| 工具坞、顶部动作和输入框具有明显圆角         | 柔和、易接近                       | 为小控件、大容器和胶囊分别定义几何                   |
| 图标以细线轮廓为主，留白较充分               | 精细、轻盈                         | 统一线宽、端点、留白和视觉大小                       |
| 底部当前工具使用深色圆形底，其他工具保持浅色 | 焦点集中，选中状态明确             | 深色实底只强调少量关键动作或当前工具                 |
| 文字大多为常规字重，状态文字退到次级         | 内容可读，操作区不争抢注意力       | 通过间距、字号与灰阶建立层级，减少连续加粗           |
| 输入框与工具坞有柔和阴影                     | 浮层具有空间归属                   | 阴影用于真实浮层，普通列表和卡片保持平整             |

## 图标更新方案

将全量 UI 操作图标当成同一个设计集合；本轮采用现有 Lucide 统一描边的路径，独立画布中的自有 SVG 同步处理。若后续决定重绘，代表样本可覆盖选择、平移、添加、文本、形状、图片、引用、重新生成、撤销、重做、历史、导出、附件、发送、搜索和设置，正式清单只包含产品实际存在的入口。

- 使用统一 24×24 设计坐标系，圆端点、圆连接、单色轮廓；主工具图标以 18–20px 为试作尺寸，描边从 1.5 开始比较。
- 在 16px 小尺寸上逐枚检查孔隙和笔画分离，必要时简化路径或适当加粗；线条在实际显示尺寸下必须可辨识。坐标中的 1.5 并不等于所有尺寸上固定 1.5 CSS px。
- 校正视觉居中与体积：箭头、手形、加号和方框不能只按相同外接框认定大小一致。复合图标减少内部细节，圆形与斜线做光学校准。
- hover/选中主要通过底色和前景变化呈现，不同时换图形、加粗和缩放。保留文字提示、键盘焦点和明确的可访问名称。
- 自有操作图标全部纳入统一；第三方 Agent/模型标识保持可识别轮廓，统一尺寸和留白；作品内容中的图标按画稿语义处理，不跟随界面主题改变。
- 若另行授权重绘，交付应为可编辑 SVG 及对应语义清单。AI 生成可用于比较风格与轮廓，但生成的位图探索板还需矢量整理和逐枚校准，不能直接充当生产图标资产。本轮没有生成调用或新增图标资产。

备选与代价：

| 路径                                     | 收益                                         | 代价与建议                                                                            |
| ---------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------- |
| 现有 Lucide 统一细线规范，再校准自有 SVG | 复用面广，容易覆盖所有入口，通用图形语义成熟 | 个性有限；建议作为第一组对比的基线                                                    |
| 完整自有 SVG 图标家族                    | 可统一全部光学细节，形成 Molly 的识别特征    | 需逐枚维护小尺寸、暗色和状态；先评审代表图标，再决定是否扩大重绘                      |
| 全套 AI 生成后矢量整理                   | 可快速比较风格方向                           | 独立生成容易出现几何与语义不一致，仍需人工/矢量校正；不预设生成调用预算或替代成品验收 |

[Lucide 官方文档](https://lucide.dev/guide/react/basics/stroke-width)确认描边可配置，并说明缩放会影响实际显示线宽；这仅支持技术可行性，不证明其默认图形符合本提案。当前仓库依赖为 v0 系列，实施时核对本地 API，不从现行 v1 文档直接搬入新属性或顺带升级依赖。

## 实施归属与验收建议

共享 React 控件、主题与图标使用点由 `packages/components` 承接；原生 dock 和选区栏由 `packages/design-bento/src` 的现有适配承接。Bento 是独立原生视图，外层 CSS 不能跨视图统一图标与浮层；也不能通过任意提高 React 的 z-index 实现覆盖。复用现有主题和资源装配，不增加图标运行时服务或改动固定 vendor 源码。

第一批以 dock、输入框和用户气泡组成可比较的视觉切片；共享描边与圆角同时影响复用这些定义的菜单、侧栏、设置等控件，但不据此重排它们。验收需要浅/深主题、实际尺寸下的细线清晰度、中英文、窄窗口，以及 hover/选中/禁用/键盘焦点；画布相关变更沿用现有真实 Electron 合成截图要求，不能只看放大的 SVG。按钮增大与圆角增加可能压缩工作区，必须在窄窗口同时比较空间占用和可读性。

## 第一批实施

- 图标：共享 `svg.lucide` 采用 1.5 描边，覆盖分散的组件属性值；原生 dock、形状菜单与选区工具栏同步为 1.5。保留路径、语义、圆端点和圆连接，选择工具由填充改为轮廓。8px 下拉小箭头保留 3 的坐标描边以维持约 1px 的可辨识线宽；第三方标识、作品与图表不受选择器影响。
- 工具坞：胶囊外形、38px 圆形按钮、20px 图标、4px 间隙与柔和阴影，当前选择仍以反色圆形标记。形状菜单保持已有五个入口，仅调整圆角与描边。
- 窄画布：第一轮实机截图发现变大的 dock 与缩放/保存提示重叠；在原生视图宽度不超过 640px 时，将 dock 底距改为 64px，形状菜单同步上移。极窄 dock 可横向滚动，按钮不被挤小，不增加新工具或状态。
- 输入框：会话与起始页共享 24px 圆角、可编辑字段表面和柔和阴影；会话输入留白增大，桌面发送按钮为 36px。引用 chip 遮罩与字段底色保持相同，保留外框焦点信号与既有提交逻辑。
- 用户消息：18px 圆角、6% 前景 tint 背景、正常文字色和更宽松内边距；删除专用于反转气泡的引用 chip 颜色覆盖。长消息折叠、搜索和文本选择逻辑继续复用。
- 圆角：共享 sm/md/lg/xl/2xl 阶梯为 8/10/12/16/24px；同步基础层和宿主的无层覆盖，避免打包后 token 被 Tailwind 默认值覆盖。

## 限制与待判断

本轮不改变 Agent 生命周期、保存/只读协议、画稿数据或 native 视图归属，没有提交或发布。参考图之外的 Seede 交互、精确 token 和图标来源尚未核实；这些值是 Molly 的实现选择。共享样式已覆盖相应操作图标；设置页的追加检查范围见下，小尺寸图标的清晰度和整体视觉品质仍需要用户判断。暗色截图中原生画布网格的浅色背景为既有行为，本轮仅同步其操作浮层的图标样式。第二批顶部动作区及工作台排版的后续实施见下；整体布局重排与全套图标重绘仍未实施。英文翻译待补，产品 Spec 保持原有 draft 状态。

## 设置页追加实施

第一批仅让设置页继承全局描边和圆角，没有逐页重排或验收。用户追加要求后，检查桌面本地实际存在的九个标签：偏好、外观、快捷键、Agents、Agent 角色、图像连接、MCP、项目、关于。

- 外框和导航：设置弹窗采用柔和遮罩与 24px 圆角；侧栏宽 208px，导航行至少 40px、18px 图标、1.5 描边，选中态用 6% 前景 tint。为 Agents 补齐可见页标题；项目页保留自身标题和内部滚动。
- 设置分组：复用 `CompactSection` / `CompactRow`，以实色卡片、较淡边框和 24px 圆角组织内容，去除分组标题独立深色底及重复分隔。行使用 20px 水平、16px 垂直内边距；说明为 12px、舒展行高。标签列继续占剩余宽度，控件列按内容收缩，不增加断点固定标签宽度。
