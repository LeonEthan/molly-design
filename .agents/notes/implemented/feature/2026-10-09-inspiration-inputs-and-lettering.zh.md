# 灵感图作为输入、文案取自原文与艺术字图层

Status: implemented
Translation: current

[English](2026-10-09-inspiration-inputs-and-lettering.md)

## 摘要

[用户选择设计方案](2026-10-09-user-chosen-designs.zh.md)的首批运行还原度较高，但暴露出三个缺口：Skill 禁止把找到的参考传给图片模型，方案只由原海报和提示词生成；Agent 从方案图片上读取文案，导致文案被遗漏或改动；艺术化的产品名被压平为普通字体。本次更正允许 Agent 将从调研中自选的一到两张灵感图与原图一起作为 `edit` 输入；所有文案取自需求或原图并逐行核对；字体无法还原的艺术字无论大小都从方案中分离为图片图层。Spec 仍为草案，等待负责人批准。两次 DeepSeek 重跑中所有方案都使用了灵感输入，可编辑版本与选定方案保持接近；一次通过检查，另一次生成了横版画布。

## 问题与依据

- 负责人早前要求方案必须"图加文生成，而非纯文生图"，本意是调研得到的灵感图由 Agent 灵活挑选，作为输入辅助文本和原图生成。[方向优先的 Skill 更新](../simplification/2026-10-09-graphic-design-skill-refresh.zh.md)将其理解为原图和草模，并写成了相反的规则："找到的参考图从不作为编辑输入"。本次是对该理解的更正。
- 在提交 adfd3cd7 上完成的两次瑞幸重新设计 DeepSeek 运行中，三个方案都是 `edit` 调用，唯一输入是原海报。
- 两次运行中，方案里以艺术字加彩色底块呈现的饮品名"小黄油美式""小黄油拿铁"都变成了原生文本（其中一次放在纯色形状上）。Skill 原先要求风格化标题先尝试原生文本，并把图片艺术字限制为少量大号展示字。
- 一次运行在"*全网爆火全冰去水隐藏喝法，口感加倍浓郁"上未通过文案检查，另一次遗漏了免责声明：Agent 照搬了方案画出的文字，而阶段 1 在用到文案之前就要求列出文案。
- 两次运行的调研都只看了搜索结果网格。

## 决定

1. **调研保存灵感图。**逐张打开图片而非只看结果网格，并用 `save_image` 保存方案可能用到的一到三张灵感图。
2. **方案以图加文生成。**`edit` 输入依次为：有原图时先放原图，再放为该方案挑选的一到两张灵感图，最后是可选的草模。提示词写明每张图贡献的特质，并禁止出现其物体、人物、文字和标志。不同方案可用不同灵感图。一眼看出是某张参考换了文案的方案不合格。各连接的输入上限以 `imagegen` Skill 为准。
3. **文案取自原文。**阶段 6 的每行文案都取自需求或原图，包括小字，而非方案图片；阶段 8 逐行核对。阶段 1 不再列出文案。
4. **艺术字图层。**判据是原生文本能否还原方案的字形与效果。不能时（手绘字形、描边加填充、纹理、3D、与底色块融为一体、变形或逐字样式），无论大小都从选定方案中分离为图片，底色块属于它时一并分离，并逐字对照原文核对。长文案和小字保持原生文本。

评测运行器的过程计数现在只统计 Agent 实际发起的图片调用，不再把提到这些工具的文档计入。

## 备选方案

- **继续不让参考进入图片模型：**避免照搬他人作品，但光线、配色和字体处理只能靠文字描述，而负责人的要求正是文字难以表达这些。改为用"可认出的照搬即不合格"规则和提示词禁令应对这一风险。
- **固定参考数量或强制使用参考：**负责人否决；数量和选择由 Agent 决定。
- **标题以下一律用原生文本：**编辑简单，但会丢失设计，饮品名即是例子。

## 局限

- 灵感输入可能使方案过于接近某张参考；目前只靠 Agent 自查和负责人判断。
- DashScope 最多接受三张输入图，有原图时只剩一到两张参考的位置。
- 艺术字图层只能通过重新生成来修改文字。
- 运行中看到的底图问题（人物留在底图中、标志字丢失、拼接痕迹）不在本次范围内。

## 重跑

在提交 9c4eb5fe 上对瑞幸重新设计用例做了两次 DeepSeek flash 运行，由运行器选择 Agent 推荐的方案。视觉质量由负责人判断，以下仅为观察。

- **运行 1（检查通过）。**保存了四张灵感图；每个方案都以原海报加一张不同的灵感图 `edit` 生成，得到清透、深钴蓝、蓝黄三个明显不同的方案。方案 A 的可编辑版本与其高度一致，原文每一行（含免责声明）都在。方案 A 的饮品名是深蓝底块上的普通粗体字，因此用原生文本是忠实的选择。共 11 次图片编辑。回复中方案 B 的图片路径混用了两个文件哈希，显示"File was not found"。
- **运行 2（检查未通过）。**方案使用原图加一到两张灵感图。Agent 把"保持海报尺寸不变"理解为未改动的 800×600 默认画布，而非附件海报的 1126×1500，因此方案和结果都是横版。在该画布内还原忠实，文案各行齐全，并纠正了方案中挂反的饮品标签。共 7 次图片编辑。

待跟进：当前画布是未改动的默认画布时，重新设计要保持的尺寸应以用户提供的作品为准；方案图片可先复制为短文件名再嵌入，避免手抄路径；底图仍会丢失手持杯上的标志字。
