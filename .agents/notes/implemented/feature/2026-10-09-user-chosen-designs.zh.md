# 由用户选择设计方案并忠实还原

Status: implemented
Translation: current

[English](2026-10-09-user-chosen-designs.md)

## 摘要

负责人对生成式分层设计的本意是：设计由图片模型创作，用户从至少三个完整设计中选择一个，`design.yaml` 只负责把选定的设计还原为可编辑形式。书面记录却写成由 Agent 挑选最佳"草稿"，并只把草稿当作宽松参考来重建作品，导致 Agent 在重建时重新设计，评测结果看起来像套在模板上的重新排列的抠图。本次更正让 Skill 提供至少三个完整设计方案，结束回合等待用户选择，再忠实还原选定方案：从方案编辑得到背景底图，从方案中分离物体，并按方案匹配文字。负责人已于 [2026-10-09](../../../../.github/spec-approvals.md#2026-10-09-user-chosen-designs) 批准工作流 Spec 修订；输出质量在评测运行中另行判断。

## 问题与依据

- 已批准的 Spec（2026-09-25）写的是"生成多份整图构图草稿，由 Agent 择优"，第 4 步"以选定草稿为参考"重新生成元素。[最初方案](2026-09-24-generative-layered-design-workflow.zh.md)记录为"由 Agent 挑选最佳草稿；以后的'自动'选项可区分 Agent 与用户选择"。Skill 还加了"草稿只指导重建，从不成为作品或接近完整的背景"。
- 负责人于 2026-10-09 澄清：图片就是设计而非草稿；至少展示三个设计供用户选择；只有选定的设计才转为可编辑并精修。
- 在[方向优先版 Skill](../simplification/2026-10-09-graphic-design-skill-refresh.zh.md) 上运行的瑞幸重新设计评测，产出的是带白边和硬边的抠图、通用渐变或光斑背景、黄色标签和默认粗体字。负责人认为效果一般，之后要求重新设计必须起草的修订让效果更差。质量是在语言模型重建这一步丢失的，而此前增加的流程规则都没有触及这一步。
- 未改动 `design.yaml` 的回合以 `no_artifact` 结束，对话中不显示文件回执，因此选择回合无需改动产品。

## 决定

经负责人于 2026-10-09 批准：

1. **设计方案。**新设计或重新设计由图片模型生成至少三个完整方案：按画布比例的成品海报，画出标题和主要文案，在概念或构图上各不相同。用户提供的交付素材（包括被重新设计的原海报）可作为 `edit` 输入；找到的参考图从不作为输入。草模渲染图是可选的版式辅助。方案展示前先按设计默认值评判。
2. **用户选择。**Agent 展示全部方案（A、B、C），给出推荐，请用户选择，并在不改动作品的情况下结束回合。在用户指定方案的回合继续；若用户要求 Agent 自行决定，则在同一回合继续。
3. **忠实还原。**从选定方案中去除前景物体和文字得到背景底图；从方案中分离物体；位置与尺寸从方案中量取；文字按方案匹配并使用用户的准确文案。必须保持不变的人脸、产品或标志若在方案中被改动，则从原图分离。审视时将渲染结果与选定方案并排及叠加对比。
4. **重新设计分支。**"重新设计""优化"即使带有保持人脸等约束，也属于新设计；局部修改是明确的局部改动。
5. **撤回。**此前"重新设计走图片模型草稿"的提交、其"草稿近似与最终一致性"做法，以及"只呈现一个选定方向"的回复规则。

保留：调研、方向词、提问工具、设计默认值，以及否定方向时的处理规则（现适用于用户否定全部方案时）。

评测运行器（本地分支，不属于产品）将未提交作品的回合视为选择回合，回复选择 Agent 推荐的方案，并记录该过程。负责人分别评判方案与还原效果。

## 备选方案

- **由 Agent 选择并把重建当作参考：**即原有记录的设计，因把设计质量交给语言模型重建而否决。
- **在同一回合用提问工具让用户选择：**负责人否决；结束回合能在对话中以完整大图展示方案。
- **把选定图片作为单一平面图层并叠加文字交付：**保留质量但放弃物体的独立编辑；目标仍是忠实的分层还原，允许接近完整的底图。

## 局限

- 尚无运行使用此工作流；从成品设计中得到底图和分离物体的还原度尚未验证，图片模型画出的文案可能有误。
- 新设计现在需要两个回合，并在图层工作前至少调用三次图片生成方案。
- Spec 修订已于 [2026-10-09](../../../../.github/spec-approvals.md#2026-10-09-user-chosen-designs) 获负责人批准。
