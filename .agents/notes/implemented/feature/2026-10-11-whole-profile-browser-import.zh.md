## 摘要

原有 Pinterest 导入会枚举全部浏览器资料、读取两次 Cookie，并通过通用系统工具请求钥匙串授权。用户批准改为一个导入动作、合并浏览器与用户配置选择器，以及默认折叠全选的设计与电商网站清单。本次实现由主进程一次读取配置，按所选目录过滤，精确合并 Cookie，并在 Molly 进程内访问钥匙串。合成测试验证了取消、写入隔离和恢复核验；真实签名授权与网站登录兼容性仍未验证。导入数量明确不作为登录成功证据。

## 授权与复用

[批准记录](../../../../.github/spec-approvals.md#2026-10-11-whole-profile-browser-import)取代原提案的预览令牌和后续再接钥匙串方案。弹窗只提供一个导入动作，没有预览确认阶段。共享目录包含 13 个设计和 14 个电商平台，展开显示确切域名；包含 Adobe、TikTok 共享账号域，排除通用身份提供商与任意 Shopify 店铺。目录定义导入范围，不证明网站登录兼容性。

复用阶梯：适配现有 Dialog、Select、Checkbox、Collapsible 成为共享 `BrowserAccountImportDialog`，由网站账号设置、浏览器菜单和 Pinterest 设置入口打开；适配现有 Agent 暂停、会话分区与签名策略、Cookie 事务和原生资源签名校验。固定版本 rookie 的 `read()` 替代报告加详情双读，小补丁仅替换钥匙串访问并加入配置预算。现有模块已提供必要能力，因此没有自写 Chromium 解密器、浏览器扩展、连接来源浏览器的 CDP、预览令牌存储或第二份会话数据库。

## 读取与授权

发现来源只检查应用安装位置；选择浏览器后仅读取该浏览器资料，主进程保留已知的不透明配置 ID。导入只做一次完整原生读取，含加密、会话、过期 Cookie 和分区信息。主进程按目录过滤，跳过并计数来源分区与过期 Cookie，拒绝部分读取、解密警告和未知上下文，值、密钥及文件路径不进入渲染器或 Agent 响应。原生限制为 50,000 行和 32 MiB 核心 Cookie 负载，由超限合成输入验证；这是保守产品上限，不是客户资料测量结果。

原生模块在 Molly 中调用 Security.framework，密钥只存在原生内存并清零释放。仅加载校验后的资源，npm 包只提供类型。构建、开发和打包共用固定源码归档、编译器和补丁；复用原有签名机制，在根应用签名之前更新原生资源摘要，继续校验加密 Cookie fuse。稳定签名可能保留授权，但系统策略、钥匙串设置或签名变化可再次提示。协作式超时或取消不能关闭系统弹窗；取消后的读取仍占用槽位直到原生返回，其晚到结果被丢弃，不能写入。

## 写入与生命周期

按域名、路径和名称更新匹配项，保留 Molly 独有数据。写入前暂停运行中的 Agent，阻止新 Agent 与页面操作，关闭并等待所属 WebContents 销毁，拦截请求及响应，关闭连接。同分区临时空白页枚举注册信息，启动全部 Service Worker，以原生保活任务配合调试暂停；剩余 Shared Worker 也暂停。不支持的版本或目标在修改前拒绝。单纯关闭或停止 Worker 不够：Cookie Store 订阅可在 Cookie 改变时不经网络重新启动 Worker。本次未增加全局调试端口。

完整 CDP 快照保留分区与元数据。目标分区身份冲突或容量压力在修改前拒绝。增长中的 Cookie 存储保留每注册域 170 条、总体 3,000 条的容量余量，覆盖既有身份不消耗新容量。精确删除与完整读回核验合并和恢复，排除自然过期；无法确认恢复时保留隔离，直到用户明确清理。清理覆盖 Molly 全部网站存储、缓存及 HTTP 认证缓存，不修改来源浏览器。

窗口刷新或关闭会撤销尚未写入的任务；退出应用等待已接受写入和恢复结束。释放隔离后恢复页面 URL，已关闭的所属窗口或页面消费者除外。不自动恢复 Agent。人工接管或 MFA 暂停新回合，直到明确恢复或原生页面销毁；普通暂停记录仍只约束原回合，后续任务可以继续。

## 证据与限制

- `browser-account-source.test.mjs` 验证目录边界、一次完整读取、脱敏、取消、上限、精确合并、容量和恢复核验。
- `public-browser-service.test.mjs` 验证不可用构建、所属窗口失效、单原生读取槽位、晚到页面和回合、原生销毁、退出等待、清理和接管。
- 渲染器测试覆盖默认折叠全选、单动作、结果与跳过提示、重试、取消及完成中状态、不可用构建与各入口。
- `browser-cookie-reader.test.mjs` 加载校验后的原生模块，读取合成且保持打开的 SQLite/WAL 数据库，拒绝 50,001 行配置；未读取任何钥匙串项目。
- `browser-account-probe.mjs` 在 Electron 44.7.0 / Chromium 152.0.7977.130 使用生产隔离与事务，验证正在运行和已停止的 Cookie 变化 Worker 均在释放后才继续写入；注册 Worker 暂停期间可清除全部网站数据；恢复保留仅限主机与域 Cookie、相邻路径、CHIPS 和元数据。
- 原生签名 fixture 验证模块资源在根应用签名前重新封存。
- `pnpm check`、`pnpm format`、`pnpm build` 和 `pnpm run docs check` 通过，覆盖工作区检查、本地 OSS 桌面构建和文档合同。
- Codex CLI `gpt-6-astra` high 只读意见首先指出 Worker 重启风险；实现复核发现旧接管记录阻挡新任务，已恢复按回合清理并补回归测试。该复核未建立其他可行动的 P0/P1 问题。

本次没有访问真实账号或浏览器配置，没有验证新的签名钥匙串弹窗及授权保留、Developer ID 分发、公证、升级或 27 个网站的真实登录。旧导入器的 Pinterest 实测保留为历史证据。此前临时 HTML 预览被浏览器策略阻止，未绕过，也不作为当前弹窗的视觉批准。Spec 因其他修订及尚未完成的验收继续保持 draft。
