## 摘要

根 AGENTS.md 随设计迁移决定增长，产品目标、开发协作和维护规则的层次需要区分。本次依据用户指定的官方模型指南，补充自主完成、授权延续、skill 冲突解释和适量验证的简短要求，并将设计原则前置、合并重复措辞。既有安全边界、必读链接、提交检查及已确认产品方向保持不变；目标规则与当前实现证据明确分开。仅修改根指令和本记录，不改产品行为；implemented 指文本改写已完成，不表示模型行为改善已通过评测。

## 依据与取舍

参考 [OpenAI Model guidance：Prompting best practices](https://developers.openai.com/api/docs/guides/latest-model#prompting-best-practices)（2026-09-11 读取）。采用其关于持续完成、指令冲突透明、简洁表达与按风险验证的建议，结合本仓库授权边界改写，不逐段复制提示词模板。

- 将开发者协作要求与产品内 Agent 自主性分节，保留“审查/规划不等于运行时实施授权”。
- 保留第一性原理、迁移只删减、Bento 单一真相、独立画布、hook 数据完整性、结果卡退役与 Agent 读图边界；详见[范围决定](../../proposed/simplification/2026-09-11-design-result-feedback.zh.md)。
- 全部原有文档链接目标保留；平台/共享协议/子模块等触发规则仍在根文件，不搬到默认不加载的记录里。
- 验证要求仅减少无依据的重复扩大，不豁免原有提交检查。没有导入指南的自动并行委派示例，也没有更改模型或 API 配置。

## 验证范围
