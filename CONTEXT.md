# Molly

Molly is a local desktop workbench, released independently under its own brand, for creating and finding graphic design output through design sessions.

## Language

**Artwork**:
A single-canvas design output with a name and dimensions; in the first stage it is associated with one primary design session by default.
_Avoid_: session, turn version

**Design session**:
The conversation and execution record around an artwork; a blank artwork is initialized through the existing Session submission flow. Creation follows the Agent configuration requirements; manual editing after opening is independent of Agent execution.
_Avoid_: artwork, Agent process

**Project**:
An optional grouping of multiple artworks, not a prerequisite for starting creation.
_Avoid_: mandatory Git repository, artwork directory

**Session history**:
The conversation and execution record of a design session; it is the entry point for finding design output, not a version history of the canvas.
_Avoid_: design version repository, canvas history

**Current artwork**:
The latest authoritative state saved as a BentoDoc in the local workspace; entering from session history opens this state.
_Avoid_: historical snapshot, turn version

**Artwork projection (implemented; see "Current-artwork reading and file consistency" in specs/graphic-design-platform.md)**:
YAML files (`design.yaml`, `pages/canvas.yaml`) and assets generated on demand from a consistent snapshot of the current artwork, for the Agent to read; not a new Agent artifact. PPTD is not used.
_Avoid_: second authoritative artwork, Agent draft, PPTD

**Agent authoring draft (implemented; see "Current-artwork reading and file consistency" in specs/graphic-design-platform.md)**:
The authoring files the Agent is currently modifying, associated with the artwork and version baseline it successfully read; re-syncing the current artwork does not overwrite the draft or silently change its baseline.
_Avoid_: current artwork, historical version store

**Conflict draft (implemented; see "Editing and Agent turns" and "Current-artwork reading and file consistency" in specs/graphic-design-platform.md)**:
Authoring files that failed the version check and remain in the workspace; the Agent re-reads the latest current artwork and handles the diff itself. It is not a separate candidate artwork for the user to accept/reject.
_Avoid_: candidate approval, automatic merge on apply

**Creation preview (implemented; see "One canvas and live construction" in specs/graphic-design-platform.md)**:
A readonly, uncommitted view that updates automatically as the YAML artwork projection changes; it may stay on the last valid result and changes neither the current artwork nor the Agent draft baseline. During Agent execution and artifact processing, the current artwork is also readonly; watch progress while running, then reference the current artwork's elements to continue editing after the commit completes. The preview has no manual refresh or import-into-current-artwork action (retired 2026-09-18).
_Avoid_: current artwork, completed artifact, artwork projection generated by a read hook

**Workspace**:
The local file space a session uses, holding design files and assets; it is not a new artwork-directory management feature.
_Avoid_: artwork library, migratable artwork directory

**Agent**:
The user-chosen creation and execution tool; Pi and other coding agents belong to the same category of choice, and Molly is not bound to any one of them.
_Avoid_: Molly-mandated built-in Agent

**BentoDoc**:
The single editable truth of an artwork, owned by the Bento editor; the YAML artwork projection is derived from it and is never a parallel authority.
_Avoid_: YAML source of truth, second artwork store

**Bento**:
The vendored editor and rendering engine that hosts BentoDoc canvases; it stays naive about elements' product semantics and the Agent lifecycle, while Molly owns save, readonly and command adaptation around it.
_Avoid_: agent-aware canvas, Molly-authored editor core

**Pi**:
The model engine bundled inside the desktop; one member of the Agent category, not a separate product runtime the user installs.
_Avoid_: external engine CLI, mandated default Agent

**Lody**:
The upstream project Molly is derived from; its architecture and protocol contracts are reused under Apache-2.0, and legacy `lody`-named storage and wire markers remain readable for compatibility. It is never the current product's name.
_Avoid_: Molly itself, Molly cloud
