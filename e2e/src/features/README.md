# Feature index

The active suite contains 4 scenarios: 3 `@P0` smoke journeys and 1 `@P1` deeper journey.

| Feature                      | Scope                                                                                           |
| ---------------------------- | ----------------------------------------------------------------------------------------------- |
| `onboarding.feature`         | Real Electron cold start, bundled CLI bootstrap, local catalog, and product entry               |
| `lifecycle.feature`          | Session Stop/deletion and project-folder preservation with bundled Pi and a scripted model wire |
| `browser-navigation.feature` | Local native navigation and snapshot through the real Pi/MCP/Desktop chain                      |
