# Feature index

The active suite contains 6 scenarios: 3 `@P0` smoke journeys and 3 `@P1` deeper journeys.

| Feature                      | Scope                                                                                    |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| `onboarding.feature`         | Real Electron cold start, bundled CLI bootstrap, local catalog, and product entry        |
| `lifecycle.feature`          | Session Stop, large Review, and Work/Terminal cleanup against a scripted ACP             |
| `browser-permission.feature` | Browser permission denial and private-host refusal through the real Pi/MCP/Desktop chain |
