# Feature index

The active suite contains 5 scenarios: 3 `@P0` smoke journeys and 2 `@P1` deeper journeys.

| Feature                      | Scope                                                                             |
| ---------------------------- | --------------------------------------------------------------------------------- |
| `onboarding.feature`         | Real Electron cold start, bundled CLI bootstrap, local catalog, and product entry |
| `lifecycle.feature`          | Session Stop, large Review, and Work cleanup against a scripted ACP               |
| `browser-navigation.feature` | Local native navigation and snapshot through the real Pi/MCP/Desktop chain        |
