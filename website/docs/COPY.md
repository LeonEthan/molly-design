## faq

### EN

```text
FAQ

Common questions

Didn’t find your answer? Ask on GitHub ↗

01
What do I need to run it?

A Mac with Apple Silicon running macOS Ventura or later. Intel Macs aren’t supported.

02
How do I install it?

Download the DMG, open it and drag Molly.app into Applications. The app is signed with Developer ID and notarized by Apple, so it opens normally.

03
Does it cost anything? Who pays for the models?

Molly is free to download. The providers you configure bill you directly for chat and image model use. Molly doesn’t collect or resell it.

04
Do my design files and chats get uploaded to Molly?

No. Design files, versions and chats are stored locally, and Molly has no cloud account. Model requests go straight to the providers you configure.

05
Which models can I use?

That depends on what you connect: OpenAI, Kimi Code and any OpenAI-compatible endpoint, including local Ollama and LM Studio. The image model is set up separately, and you connect it alongside the chat model on first launch. The exact list depends on the provider and your key.

06
Do I need an image model?

Yes. On first launch you connect a chat model and an image model. Molly needs both before it can start a design.

07
How is this different from asking a chat AI for a poster?

A chat tool usually hands you one flat image. Molly looks for design inspiration, puts a few directions side by side and builds the one you pick as editable layers. You can align, retype and roll back, then export PNG or JPEG on your Mac.

08
Can I make print files?

Sizes are pixel presets for now, with no bleed or millimetre units, so it suits screen and social work best.

09
How do I update?

Check for updates in the app, or download the DMG again from this page at any time.
```

系统要求是什么？

02

要付费吗？模型费用谁出？

Molly 可以免费下载。对话模型和图片模型的调用费用，由你配置的服务商直接向你收取，Molly 不代收也不转售。

支持哪些模型？

取决于你添加的连接：OpenAI、Kimi Code，以及任何 OpenAI 兼容接口（包括本地的 Ollama、LM Studio）。图片模型单独设置，首次启动时和对话模型一起接上。具体能用哪些，看服务商和你的密钥。
