## faq

### EN

```text
FAQ

Common questions

Didn’t find your answer? Ask on GitHub ↗

01
What do I need to run it?

A Mac with Apple Silicon running macOS Ventura or later. Intel Macs aren’t supported.

02
How do I install it?

Download the DMG, open it and drag Molly.app into Applications. The app is signed with Developer ID and notarized by Apple, so it opens normally.

03
Does it cost anything? Who pays for the models?

Molly is free to download. The providers you configure bill you directly for model and image use. Molly doesn’t collect or resell it.

04
Do my designs and chats get uploaded to Molly?

No. Artwork, versions and chats are stored locally, and Molly has no cloud account. Model requests go straight to the providers you configure.

05
Which models can I use?

That depends on what you connect: OpenAI, Kimi Code and any OpenAI-compatible endpoint, including local Ollama and LM Studio. Image models are set up separately. The exact list depends on the provider and your key.

06
Can I use it without an image model?

Yes. Layouts with type and shapes don’t need an image service. Image generation is optional.

07
How is this different from asking a chat AI for a poster?

A chat tool usually hands you one flat image. Molly looks for references, offers a few directions, and builds the one you pick as editable layers. You can align, reword and roll back, then export PNG or JPEG on your Mac.

08
Can I make print files?

Sizes are pixel presets for now, with no bleed or millimetre units, so it suits screen and social work best.

09
How do I update?

Check for updates in the app, or download the DMG again from this page at any time.
```

```text
常见问题

常见问题

没找到答案？ 在 GitHub 上提问 ↗

01
系统要求是什么？

一台 Apple Silicon 芯片的 Mac，系统为 macOS Ventura 或更新。目前不支持 Intel Mac。

02
怎么安装？

下载 DMG，打开后把 Molly.app 拖进「应用程序」。应用经 Developer ID 签名并通过 Apple 公证，可以直接打开。

03
要付费吗？模型费用谁出？

Molly 可以免费下载。模型和图片调用的费用，由你配置的服务商直接向你收取，Molly 不代收也不转售。

04
我的稿子和对话会上传到 Molly 吗？

不会。作品、版本和对话都存在本地，Molly 没有云账户。模型请求直接发给你配置的服务商。

05
支持哪些模型？

取决于你添加的连接：OpenAI、Kimi Code，以及任何 OpenAI 兼容接口（包括本地的 Ollama、LM Studio）。图片模型另外设置。具体能用哪些，看服务商和你的密钥。

06
没有图片模型能用吗？

可以。只用文字和形状排版不需要图片服务，图片生成是可选的。

07
和直接让聊天 AI「做张海报」有什么不同？

聊天里出图，通常给你一张扁平的结果。Molly 会先找参考、给几套方向，再把选中的方向做成可编辑的图层：可以对齐、改字、回到旧版本，最后在本机导出 PNG 或 JPEG。

能做印刷稿吗？

目前尺寸用像素预设，没有出血和毫米单位，更适合屏幕和社媒用途。
```
